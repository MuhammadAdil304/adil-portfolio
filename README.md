# Adil Portfolio

Clean, fast, and responsive modern portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Stack

- React, TypeScript, Vite, Tailwind CSS
- Framer Motion, Lucide Icons

## Setup & Running

1. Run `npm install` inside the `client` directory (or in root).
2. Run `npm run dev` to start the development server.
